# 业务分析文档 — 学生请假管理系统

> 文档版本：2026-06-23
> 基于轻量级低代码平台实现

---

## 一、业务场景选取

### 1.1 场景概述

本项目选取 **学生请假管理** 作为核心业务场景，模拟高校学生请假、辅导员审批、系主任审批的完整流程。场景属于 OA（办公自动化）领域，业务流程闭环清晰，适合多角色协作。

### 1.2 场景描述

在高校日常管理中，学生因事、因病等需要请假时，需要向辅导员提交请假申请，辅导员审批通过后，再提交系主任审批。整个流程涉及 3 个角色：

| 角色 | 职责 | 权限 |
|------|------|------|
| **学生** | 发起请假申请、查询审批进度、撤回未审批申请 | 申请提交、查询查看 |
| **辅导员** | 初审学生请假申请、填写审批意见 | 审批（通过/驳回） |
| **系主任** | 终审请假申请、填写审批意见 | 审批（通过/驳回） |

### 1.3 业务流程

```
┌─────────┐     ┌──────────────┐     ┌──────────────┐     ┌─────────┐
│  学生   │────▶│ 辅导员审批   │────▶│ 系主任审批   │────▶│  归档   │
│ 发起申请 │     │ (通过/驳回)   │     │ (通过/驳回)   │     │         │
└─────────┘     └──────────────┘     └──────────────┘     └─────────┘
                        │                      │
                        ▼                      ▼
                    驳回→结束              驳回→结束
```

**完整闭环：发 起 → 辅导员处理 → 系主任处理 → 反馈归档**

### 1.4 核心业务规则

1. 请假申请需包含：请假类型（病假/事假/公假）、开始日期、结束日期、请假原因
2. 系统自动计算请假天数（开始日期到结束日期的天数 + 1）
3. 请假申请提交后自动进入工作流：**辅导员审批 → 系主任审批**
4. 辅导员审批通过后，流转到系主任审批节点
5. 任一节点驳回，流程终止，请假记录状态更新为"已驳回"
6. 全部节点通过后，请假记录状态更新为"已通过"，流程归档
7. 学生可在审批通过前撤回申请
8. 学生可随时查看申请详情及审批进度

## 二、角色分析

### 2.1 学生角色

| 功能 | 描述 |
|------|------|
| 请假申请 | 填写请假类型、日期、原因，提交申请 |
| 我的申请 | 查看自己的请假申请列表，包含审批状态和工作流状态 |
| 查看详情 | 查看单条申请的详情和审批进度（工作流可视化） |
| 撤回申请 | 在审批通过前撤回申请 |

### 2.2 辅导员角色

| 功能 | 描述 |
|------|------|
| 待审批列表 | 查看所有需要自己审批的请假申请 |
| 审批操作 | 查看申请详情，选择通过或驳回，填写审批意见 |
| 进度查看 | 查看工作流中每个节点的审批状态 |

### 2.3 系主任角色

| 功能 | 描述 |
|------|------|
| 待审批列表 | 查看辅导员已通过、需要自己审批的请假申请 |
| 审批操作 | 查看申请详情，选择通过或驳回，填写审批意见 |
| 进度查看 | 查看工作流全流程的审批状态 |

## 三、关键业务实体

### 请假申请（leave_application）

| 字段 | 类型 | 说明 |
|------|------|------|
| student_id | LONG | 学生 ID |
| student_name | VARCHAR(64) | 学生姓名 |
| leave_type | VARCHAR(32) | 请假类型：sick(病假)/personal(事假)/public(公假) |
| reason | TEXT | 请假原因 |
| start_date | DATE | 开始日期 |
| end_date | DATE | 结束日期 |
| leave_days | INTEGER | 请假天数（自动计算） |
| status | VARCHAR(32) | 审批状态：pending/approved/rejected/cancelled |

## 四、数据源设计

| 数据源 | 用途 | 数据项 |
|--------|------|--------|
| 请假类型 | 下拉选择 | 病假(sick)、事假(personal)、公假(public) |
| 审批状态 | 列表筛选 | 待审批(pending)、已通过(approved)、已驳回(rejected) |
| 审批节点 | 流程展示 | 辅导员审批(counselor)、系主任审批(dept_head) |
