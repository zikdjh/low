# 系统分析文档 — 学生请假管理系统

> 文档版本：2026-06-23
> 分析范围：在低代码平台框架下，实现学生请假管理业务

---

## 一、系统目标

以自研轻量级低代码平台为基础，通过 **可视化实体建模 + 后端服务配置 + 前端页面设计** 的方式，快速构建学生请假管理系统，验证低代码平台在 OA 办公场景下的完备性。

**核心理念**：用低代码方式完成「实体定义 → 服务配置 → 页面组装」全流程，体现"少写代码、多配置"的低代码思想。

## 二、功能模块分析

### 2.1 功能模块划分

```
学生请假管理系统
├── 1. 申请提交模块
│   ├── 请假表单（类型、日期、原因）
│   ├── 表单验证（必填校验、日期校验）
│   └── 申请提交 + 工作流发起
├── 2. 申请查询模块
│   ├── 我的申请列表（分页、状态筛选）
│   ├── 申请详情（+ 工作流进度可视化）
│   └── 撤回操作
├── 3. 审批处理模块
│   ├── 待审批列表（按当前角色过滤）
│   ├── 审批详情 + 进度查看
│   └── 通过/驳回操作
├── 4. 工作流引擎模块
│   ├── 流程定义（审批节点配置）
│   ├── 流程实例管理
│   ├── 任务分配与流转
│   └── 流程状态查询
└── 5. 数据源服务模块
    ├── 请假类型数据源
    ├── 审批状态数据源
    └── 审批节点数据源
```

## 三、工作流引擎分析

### 3.1 流程定义

```
请假审批流程（leave_approval）

节点 0: 辅导员审批
  ├─ 审批人角色: counselor
  ├─ 操作: 通过/驳回
  └─ 通过后: 流转到节点 1

节点 1: 系主任审批
  ├─ 审批人角色: dept_head
  ├─ 操作: 通过/驳回
  └─ 通过后: 流程完成，归档
```

### 3.2 流程状态机

```
         ┌──────────┐
         │  pending  │ ← 流程启动
         └────┬─────┘
              │
     ┌────────┼────────┐
     ▼        ▼        ▼
  approved  rejected  cancelled
  (全部通过) (被驳回)  (被撤回)
     │        │        │
     └────────┴────────┘
              │
              ▼
         archived (归档)
```

### 3.3 工作流数据模型

| 表名 | 说明 |
|------|------|
| lc_workflow_instance | 工作流实例：记录每次流程的发起人、状态、当前节点 |
| lc_workflow_task | 工作流任务：记录每个审批节点的审批人、意见、时间 |

## 四、核心服务分析（3个）

### 4.1 数据查询服务

- **端点**: `GET /lowcode/leave/records`
- **功能**: 查询请假记录，支持分页、按学生 ID/状态/请假类型筛选
- **体现低代码思想**: 通过 `DynamicDataService` 通用 CRUD 引擎，无需为请假表单独写 SQL，列名/表名由实体元数据驱动

### 4.2 数据源服务

- **端点**: `GET /lowcode/leave/datasources`
- **功能**: 返回请假类型、审批状态等下拉列表数据，支持前端动态加载
- **体现低代码思想**: DataSource 配置化，前端表单组件通过声明式配置即可绑定数据源

### 4.3 数据库操作服务

- **端点**: `POST /lowcode/leave/apply`、`POST /lowcode/leave/approve`、`POST /lowcode/leave/reject`
- **功能**: 请假申请提交、审批通过/驳回，涉及数据的增删改查
- **体现低代码思想**: 业务操作封装为服务，通过 REST 接口暴露，前端通过可视化组件调用

## 五、接口设计（API 规范）

| 方法 | 路径 | 说明 | 认证 |
|------|------|------|------|
| GET | `/lowcode/leave/datasources` | 获取数据源 | 是 |
| POST | `/lowcode/leave/apply` | 提交请假申请 | 是 |
| GET | `/lowcode/leave/records` | 查询请假记录 | 是 |
| GET | `/lowcode/leave/detail/{id}` | 查看详情 | 是 |
| GET | `/lowcode/leave/pending-approvals` | 待审批列表 | 是 |
| GET | `/lowcode/leave/workflow-progress/{id}` | 工作流进度 | 是 |
| POST | `/lowcode/leave/approve` | 审批通过 | 是 |
| POST | `/lowcode/leave/reject` | 审批驳回 | 是 |
| POST | `/lowcode/leave/cancel` | 撤回申请 | 是 |
| GET | `/lowcode/leave/my-applications` | 我的申请 | 是 |
| GET | `/lowcode/leave/approval-nodes` | 审批节点定义 | 是 |

**统一响应格式**：
```json
{ "code": 1, "msg": "success", "data": { ... } }
// code=1 成功, code=0 失败
```
