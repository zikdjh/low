## 验收 Checklist

完成 Phase 2 前需逐项打勾：

- [ ] EntityMeta / PageSchema 修改不影响线上，必须经 release 上线
- [ ] 任意历史 release 一键回滚，5 秒内对终端用户生效
- [ ] 业务应用菜单可在管理端拖拽配置
- [ ] 任意 release 可下载完整工程 zip（Spring Boot + Vue），IDE 内可编译运行
- [ ] 项目无 `leave_` 前缀的页面 / 菜单硬编码
- [ ] `AppRuntime.vue` 与 `PageViewer.vue` 共用唯一 `SchemaRenderer`
- [ ] 发布流水线审计可在 `/lowcode/release/{id}` 查看阶段日志
